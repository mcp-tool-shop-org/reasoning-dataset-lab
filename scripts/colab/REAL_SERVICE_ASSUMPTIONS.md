### 3. Gate Disk Preflight Requirement (`REQUIRED_VM_DISK_BYTES`)

- **Subtotal (weights + venvs):**
  - `49,451,597,039 + 11,117,240,526 = 60,568,837,565` bytes (`56.41 GiB`)
- **Required free space with `+15%` margin (`ceil(subtotal * 1.15)`):**

- **Enforcement (`scripts/colab/vm_judges.py:1519-1608`):**
  - `--step gate` checks `shutil.disk_usage` on `/content` and `args.hf_home` (`/content/hf_home`), logs `content_free_bytes`, `hf_home_free_bytes`, and `required_bytes` on the `VM_GATE_OK` line, and refuses with `VM_DISK_INSUFFICIENT` (exit code `2`, `status.json` `failure_class="VM_DISK_INSUFFICIENT"`) before any archive or item file is uploaded if either path has fewer than `69,654,163,200` bytes free.

### 4. `HF_HOME`, Download Path, and Rate Limits

- **Default `HF_HOME`:** `/content/hf_home` (`scripts/colab/vm_judges.py:1421-1424`), with snapshots stored under `/content/hf_home/hub/models--<owner>--<repo>/snapshots/<revision>` (`scripts/colab/vm_judges.py:495-527`). Google Drive paths (`/content/drive`, `/gdrive`) are refused (`FORBIDDEN_STORAGE_PATH` at `scripts/colab/vm_judges.py:232-240`).
- **Async load mitigation:** `HF_DEACTIVATE_ASYNC_LOAD=1` is set in both venv environments (`scripts/colab/vm_judges.py:448`) and during judge execution (`scripts/colab/vm_judges.py:833`).
- **Rate limits:** If `HF_TOKEN` / `HUGGING_FACE_HUB_TOKEN` is supplied to avoid anonymous shared-IP HTTP 429 rate limits on HuggingFace Hub, it is scrubbed from all rig and VM logs (`scripts/colab/launch_judges.sh:186-187`, `scripts/colab/vm_judges.py:201-204`, `scripts/colab/vm_judges.py:259-260`).
