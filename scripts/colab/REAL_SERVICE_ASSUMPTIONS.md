### 3. Gate Disk Preflight Requirement (`REQUIRED_VM_DISK_BYTES`)

- **At gate time (`--step gate`), receipts are not yet uploaded to the VM:** `compute_required_vm_disk_bytes()` (`scripts/colab/vm_judges.py:1478-1491`) therefore always uses the constant `EXPECTED_WEIGHTS_TOTAL_BYTES = 49,451,597,039` (`scripts/colab/vm_judges.py:74`), which is verified by `test_real_service_assumptions_weights_table_matches_receipts` (`tests/test_colab_judge_launcher.py:2287-2348`) against the five `<owner>__<repo>.sha256.json` receipts.
- **Subtotal (weights + venvs):**
  - `49,451,597,039 + 11,117,240,526 = 60,568,837,565` bytes (`56.41 GiB`)
- **Required free space with `+15%` margin (`ceil(subtotal * 1.15)`):**
  - `ceil(60,568,837,565 * 115 / 100) = 69,654,163,200` bytes (**`64.87 GiB`**) (`REQUIRED_VM_DISK_BYTES` at `scripts/colab/vm_judges.py:84-88`).
- **Enforcement (`scripts/colab/vm_judges.py:1494-1635`):**
  - `--step gate` checks `shutil.disk_usage` on `/content` and `args.hf_home` (which matches the run's `HF_HOME` via `build_gate_env_args` at `scripts/colab/launch_judges.sh:201-208`, defaulting to `/content/hf_home`), logs `content_free_bytes`, `hf_home_free_bytes`, and `required_bytes` on the `VM_GATE_OK` line, and refuses with `VM_DISK_INSUFFICIENT` (exit code `2`, `status.json` `failure_class="VM_DISK_INSUFFICIENT"`) before any archive or item file is uploaded if either path has fewer than `69,654,163,200` bytes free.

### 4. `HF_HOME`, Download Path, and Rate Limits

- **Matching `HF_HOME` across `gate` and `run`:** `launch_judges.sh` passes `--env "HF_HOME=$HF_HOME"` (when `HF_HOME` is set) to both `--step gate` (`build_gate_env_args` at `scripts/colab/launch_judges.sh:201-208`) and `--step run` (`build_exec_env_args` at `scripts/colab/launch_judges.sh:236-238`). When `HF_HOME` is unset, `vm_judges.py` defaults `--hf-home` to `/content/hf_home` (`scripts/colab/vm_judges.py:1430-1434`), with snapshots stored under `$HF_HOME/hub/models--<owner>--<repo>/snapshots/<revision>` (`scripts/colab/vm_judges.py:613-641`). Google Drive paths (`/content/drive`, `/gdrive`) are refused (`FORBIDDEN_STORAGE_PATH` at `scripts/colab/vm_judges.py:242-250`).
- **Async load mitigation:** `HF_DEACTIVATE_ASYNC_LOAD=1` is set in both venv environments (`scripts/colab/vm_judges.py:458`, `543`) and during judge execution (`scripts/colab/vm_judges.py:843`).
- **Rate limits:** If `HF_TOKEN` / `HUGGING_FACE_HUB_TOKEN` is supplied to avoid anonymous shared-IP HTTP 429 rate limits on HuggingFace Hub, it is scrubbed from all rig and VM logs (`scripts/colab/launch_judges.sh:186-187`, `scripts/colab/vm_judges.py:211-214`, `scripts/colab/vm_judges.py:269-270`).
